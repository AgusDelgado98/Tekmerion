# Portfolio story — Tekmérion

## Problema

Las vacantes Data/BI/AI están dispersas, incompletas y difíciles de convertir en evidencia accionable sin mezclar “opinión del modelo” con “dato medido”.

## Decisión

Separar estrictamente:

1. **Analytics determinista** (conteos, skills, roles, rankings)
2. **Generación grounded** (narrativa solo sobre evidence, con guardrails)

## Resultado

Un sistema que puede obtener, procesar, consolidar, comparar y explicar señales de mercado con trazabilidad (refs, fingerprints, tests offline).

## Diferenciador

El LLM no es la fuente de verdad: interpreta un `GroundingPayload` y falla si inventa números, rankings o skills fuera de scope.
